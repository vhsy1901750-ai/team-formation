# 팀 편성 웹 앱 구현 계획

> **에이전트 작업자용:** 이 계획은 superpowers:executing-plans로 작업 단위마다 차례로 구현한다. 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 공고의 규칙을 지키고 3장 표의 기능을 모두 어려운 해결로 만든 팀 편성 Streamlit 앱을 Streamlit Community Cloud에 배포한다.

**구조:** 규칙 판단(지원 검사, 필수 역할 계산, 배정안 검사, 되추적 배정, CSV 읽기, AI 응답 읽기)은 DB와 Streamlit을 모르는 순수 함수로 `tf/` 패키지에 둔다. DB 작업은 `tf/db.py`가 트랜잭션 단위 함수로 감싸고, 화면은 `streamlit_app.py` 하나가 이 함수들을 부른다. 로그인 뒤 화면 본문 전체를 `st.fragment(run_every=3)` 하나로 감싼다.

**기술:** Python 3.12, Streamlit 1.66, psycopg 3.3 + psycopg_pool, bcrypt 5, requests, python-dotenv, pytest 9

**설계서:** `docs/PRD.md` (이 계획은 PRD를 근거로 하므로 함께 읽는다)

## 전체 제약

- 테이블 이름은 모두 `tf_`로 시작한다.
- 화면 key는 PRD 7절 표와 글자 하나까지 같다. key에는 영문, 숫자, 밑줄만 쓴다.
- `result`, `assign_status` 안내의 첫 단어는 `승인`, `대기`, `거절`, `막힘` 가운데 하나이고 뒤에 `: 이유`가 온다.
- 역할 6개: `기획자`, `웹 프로그래머`, `프론트엔드 디자이너`, `테스터`, `보고서 작성자`, `발표자`. 필수 포함 역할: `기획자`, `웹 프로그래머`.
- 팀 인원 2~4명, 지원 단계의 정원 4명.
- AI 모델마다 전체 대기 시간 120초. 모델은 3개, `openrouter/free`는 쓰지 않는다.
- 비밀 값 이름: `OPENROUTER_API_KEY`, `DATABASE_URL`, `ADMIN_PASSWORD`. 값을 출력하는 코드는 두지 않는다. 읽을 때 앞뒤 공백과 줄바꿈을 지운다.
- 학생 비밀번호는 `1234`, 관리자 학번은 `admin`. 비밀번호는 bcrypt 해시로만 저장한다.
- 연습 시나리오의 학생 이름, 학번, 순서를 앱 코드에 쓰지 않는다(테스트 코드에만 씀).
- 새 파일 첫머리에 `# YYYY-MM-DD HH:MM KST` 생성 일시를 단다.
- 사용자에게 보이는 한국어 문장은 가운뎃점 대신 쉼표를 쓰고, 보조용언을 띄어 쓴다.

## 검토할 때 볼 점

테스트가 직접 다루지 않기 쉬운데 실제로 사용자를 괴롭힐 만한 경우다. 각 줄의 테스트를 해당 작업에 넣었다.

1. CSV에 BOM, 값 앞뒤 공백, 마지막 빈 줄, `기획자 ; 발표자`처럼 공백 섞인 구분자가 있음 → 문제없이 읽는다 (작업 3 `test_parse_tolerates_bom_spaces_blank_lines`).
2. Streamlit Secrets의 관리자 비밀번호를 바꾼 뒤 앱이 다시 시작됨 → 새 비밀번호로 로그인되고 옛 비밀번호는 안 된다 (작업 4 `test_ensure_admin_updates_changed_password`).
3. AI가 JSON을 코드 블록(```json)이나 설명 문장 사이에 넣거나 학번을 숫자로 줌 → 읽어 낸다 (작업 5 `test_parse_plan_accepts_fenced_and_numeric`).
4. AI 배정안에 이미 팀이 있는 학생이나 없는 학번이 들어 있음 → 검사 실패로 다음 모델로 넘어간다 (작업 2 `test_validate_plan_rejects_unknown_and_assigned`).
5. 마감 뒤 빈 팀이 남았는데 팀이 없는 학생이 모자람 → AI를 부르지 않고 이유를 보여 준다 (작업 2 `test_explain_infeasible_empty_team`).

def test_check_apply_order():
    assert check_apply(s(1, "기획자"), [], closed=True, has_team=True, has_pending=True) == "모집이 마감됨"
    assert check_apply(s(1, "기획자"), [], closed=False, has_team=True, has_pending=True) == "이미 팀이 있음"

    teams = {1: [s(1, "기획자"), s(2, "웹 프로그래머")], 2: []}
